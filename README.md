# 残業ゲーム(オンライン対戦サーバー版)

ババ抜きベースのカードゲーム。URLを共有するだけで、アカウント不要・権限不要で友達と遊べます。
追加パッケージは不要(Node.js 18以上だけで動きます)。

## ファイル構成
- `server.js` … サーバー本体(ゲーム進行・通信)
- `public/index.html` … ゲーム画面
- `cards.json` … カードの定義(名前・枚数・効果の説明)
- `package.json` … 起動設定
- `test.js` … 動作確認用(なくても動きます)

## 自分のPCで試す
```
node server.js
```
ブラウザで http://localhost:3000 を開く。同じWi-Fiの別端末からは `http://<PCのIPアドレス>:3000`。

## ネットに公開する(例: Render の無料枠)
1. このフォルダをGitHubの新しいリポジトリにアップロードする(zipを展開して push)。
2. https://render.com でアカウントを作り、「New +」→「Web Service」→ そのリポジトリを選ぶ。
3. 設定:
   - Runtime: `Node`
   - Build Command: 空欄(または `npm install`)
   - Start Command: `node server.js`
   - Instance Type: `Free`
4. 「Create Web Service」を押す。数分で `https://○○.onrender.com` が発行される。
5. そのURLを開き、「ルームを作って友達と遊ぶ」→「招待リンクをコピー」して友達に送る。

Railway / Fly.io / さくらのVPS など、Node.js が動く場所ならどこでも同じです(起動は `node server.js`、ポートは環境変数 `PORT` を自動で読みます)。

## 注意点
- 無料枠のサーバーは、しばらくアクセスがないと眠ります。最初のアクセスは起動待ちで30秒〜1分ほどかかることがあります。
- ルームの情報はサーバーのメモリ上だけにあります。サーバーが再起動すると、進行中のルームは消えます。
- サーバーは必ず1台(1インスタンス)で動かしてください(複数台にすると、同じルームの人が別のサーバーに振り分けられて遊べなくなります)。
- 1時間以上誰も接続していないルームは自動で削除されます。

## 遊び方の仕様
- ルームは最大6人。3人に満たない分はCPUが入ります。
- ゲーム中の途中参加はできません(ゲーム終了後に参加できます)。
- 途中でやめた人(または45秒以上操作しない人)は、自動でランダム操作 / CPUに置き換わります。
- 手札はサーバーが持っていて、各自の画面には自分の手札だけが送られます(他人の手札は見えません)。
